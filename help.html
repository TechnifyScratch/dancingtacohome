Help

Set up Dancing Taco, change Carlos’s settings, and get help with Pro.

Get Carlos dancing

  1. Open the Dancing Taco Chrome Web Store listing and select Add to Chrome.
  2. Open a regular webpage in Chrome. If a tab was already open when you installed Dancing Taco, refresh it.
  3. Open Chrome’s Extensions menu and select Dancing Taco. Pin it if you want to reach it from the toolbar.

Change Carlos’s settings

Choose one of the four corners, adjust his size, or switch off Enabled to hide him. Try the switch in the website preview.

Carlos isn’t showing up

Check that Enabled is on, then refresh the page. Try a regular site if you’re on the Chrome Web Store, a Chrome settings page, or a new tab. Chrome restricts what extensions can do on those pages.

Pro and billing

Pro is coming soon. See what’s planned for Pro. For questions about an existing subscription, contact support.

Still need help?

Email contact@heyrivo.com. Tell us what you were trying to do and what happened. If Carlos is missing, include the page where you expected to see him.
